# Структуры данных и сортировки на Python

Домашка: свои реализации структур данных и сортировок, тесты и запуск тестов на CI.

## Что внутри

Структуры (папка `structures/`):
- `linked_list.py` — односвязный список
- `dynamic_array.py` — динамический массив
- `deque.py` — дек на двусвязном списке
- `avl_tree.py` — АВЛ-дерево (вставка, поиск, удаление, повороты)
- `hash_table.py` — хэш-таблица (метод цепочек)
- `lru_cache.py` — LRU-кэш (хэш-таблица + двусвязный список)

Сортировки (папка `sorts/`):
- `bubble_sort.py` — пузырьком
- `quick_sort.py` — быстрая

Тесты лежат в `tests/`, по одному файлу на каждую структуру.

## Как запустить тесты

```
pip install -r requirements.txt
pytest
```

## CI

Файл `.github/workflows/tests.yml`. GitHub сам запускает `pytest` при каждом
push и pull request. Результат виден во вкладке Actions в репозитории.

## Что важно знать про код

- Быстрая сортировка рекурсивная. Если в массиве больше ~1000 одинаковых элементов,
  то упрётся в лимит рекурсии питона. Для учебных целей хватает.
- В АВЛ-дереве одинаковые ключи не хранятся.
- У LRU-кэша `get` для отсутствующего ключа возвращает `None`.
